# NFL dual-source depth audit

The NFL DFS roster path stores Sleeper `depth_chart_order` and `depth_chart_position` in `ff_players.metadata.sleeper`. FantasyPros API observations currently supply injuries and optional projections, but the API contract in this repository has no NFL depth endpoint. The published FantasyPros team depth page is captured separately by `research/nfl_dual_depth_audit.py`.

Run `python -m research.nfl_dual_depth_audit --season 2026 --team WSH --output artifacts/nfl-depth/WSH-2026-10-04.json` before interpreting a depth-based replacement. The command reads the current Sleeper roster and its latest successful source snapshot in a read-only transaction, then downloads the published FantasyPros team depth page. It writes the Sleeper snapshot time, FantasyPros retrieval time, both response digests, identity method, source ranks, Sleeper alignment, and explicit conflicts and unmatched rows. FantasyPros does not publish a verified update time on this page, so retrieval time is not treated as publication time. Its output is a research snapshot, not a model or lineup update.

The comparison matches FantasyPros player IDs when available, falling back to a unique same-team name and position. Ambiguous identities stay unmatched. A missing or malformed FantasyPros page fails the capture; it never produces a one-source agreement. Rank disagreements require review. A morning Sleeper record for Washington listed Burks as SWR/WR4, while a later FantasyPros page listed him WR3 after McLaurin's absence. Those observations were at different times and cannot establish a simultaneous pre-lock disagreement. Neither rank is a route or target forecast. Preserve a separate official inactive-list timestamp before making a game-day eligibility decision.

This audit reads **current** records. For historical pre-lock claims, use captures saved before the decision cutoff. Running it after kickoff cannot reconstruct what FantasyPros displayed before lock.
